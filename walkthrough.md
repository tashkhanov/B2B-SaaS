# ✂️ Отчёт об адаптации B2B-платформы под барбершоп «Brohouse» (Ташкент)

## 📌 1. Обзор проекта
Система онлайн-записи и управления записями для премиального барбершопа **Brohouse** (`@brohouseuz`, Ташкент) полностью развёрнута и адаптирована:
- **Telegram Bot + AI Консультант**: интеллектуальная запись через Google Gemini 2.5 Flash, знание полного прайс-листа, мастеров, локации, телефона и условий акций.
- **Telegram Mini Apps (3 интерфейса)**:
  1. `client.html` — стильный интерфейс онлайн-записи для клиентов с выбором категорий услуг, горизонтальной каруселью мастеров, выбором даты и слотов.
  2. `index.html` — панель администратора для управления записями, ручного бронирования и статусов.
  3. `barber.html` — рабочий экран мастера с расписанием на день, статистикой, кнопками подтверждения/отмены и тумблером смены.
- **Backend & Database**: aiohttp + aiogram 3, SQLite (`barbershop.db`), синхронизация часового пояса Ташкента (`Asia/Tashkent`, UTC+5).

## ⚡ 4. Умный автоподбор и возможности мастеров

1. **Кнопка смены мастера (`barber.html`)**:
   - Эндпоинт `/api/barber/my-schedule` явно передает `is_on_shift`, а фронтенд имеет fallback на `is_working_today`. При входе кнопка сразу активна и горит зелёным («На смене»).
2. **Управление записями для мастеров (Подтверждение / Отмена / Завершение)**:
   - **В Telegram push-уведомлении**: мастер получает кнопки `[ ✅ Подтвердить ]` и `[ ❌ Отклонить ]`. При клике статус обновляется, а клиент получает push-сообщение.
   - **В WebApp кабинете (`/barber`)**: под каждой карточкой выведены быстрые кнопки действий:
     - `new`: `[ ✅ Подтвердить ]` и `[ ❌ Отменить ]`.
     - `confirmed`: `[ 🏁 Завершить ]` и `[ ❌ Отменить ]`.
   - **В чате с ботом**: мастер может подтвердить или отменить запись голосом/текстом («Подтверди Рустама»).
3. **Алгоритм балансировки автоподбора (Least Busy + Random Tie-Break)**:
   - Шеф-мастер Mr. Akmal исключён из пула автоподбора (к нему запись только прямая).
   - Клиенты без выбранного мастера автоматически распределяются между свободными стилистами: выбирается мастер с наименьшим количеством записей на этот день. При равенстве — случайный выбор.
4. **Мобильный редизайн (`client.html`)**:
   - Вкладка «Все» убрана, по умолчанию открыта категория `✂️ Стрижки` (всего 4 услуги на экране — никакого скролла).
   - Телефон в баннере зафиксирован с `whitespace-nowrap shrink-0` и иконкой.
   - Горизонтальная карусель мастеров позволяет быстро выбрать барбера.

## 👑 7. Система биллинга, Kill Switch и Пульт Super-Admin'а (SaaS Multi-Tenant)

### 1. Модель данных (`tenant_subscription` в SQLite):
- Реестр точек сети: `tenant_slug`, `name`, `is_active`, `expires_at`, `grace_period_days` (default 2), `admin_chat_id`, `contact_phone`, `contact_name`, `last_notification_stage`.
- Начальный сид для `brohouse` с активной подпиской на 30 дней.
- Методы: `get_tenant_subscription`, `get_all_tenants`, `create_tenant`, `extend_tenant_subscription_30_days`, `toggle_tenant_active`.

### 2. Логика Kill Switch (Отключение доступа):
- Статусы: `ACTIVE`, `WARNING` (3 дня до конца), `GRACE_PERIOD` (2 дня льготного периода), `LOCKED`.
- **В Telegram-боте (`bot/middlewares.py`)**: перехватывает любые сообщения и колбэки при `LOCKED`.
  - Для клиентов: *«Система онлайн-бронирования временно недоступна. Пожалуйста, свяжитесь с салоном напрямую.»*
  - Для мастеров (`/barber`): блокирует вход в кабинет.
  - Для админа салона: сообщает об окончании срока и необходимости оплаты.
  - **Super-Admin Bypass**: запросы от `SUPER_ADMIN_CHAT_ID` пропускаются без ограничений.
- **В WebApp TMA & API (`web_app.py`)**:
  - API эндпоинты возвращают HTTP `403 Forbidden` (`{"error": "subscription_expired", "message": "Доступ приостановлен. Оплатите подписку."}`).
  - HTML страницы (`/book`, `/admin`, `/barber`) рендерят премиальный экран блокировки (темный фон, замок 🔒, контакты салона и кнопка связи с разработчиком).
  - Super-Admin bypass по токену в заголовке `X-Super-Admin-Token`, query-параметре `?token=...` или cookie.

### 3. Cron-планировщик уведомлений:
- Асинхронный фоновый цикл `run_billing_notifier(bot)` раз в 24 часа.
- За 3 дня: отправляет предупреждение в `admin_chat_id` и `SUPER_ADMIN_CHAT_ID`.
- В день окончания (`expires_at`): предупреждает о начале 2-дневного льготного периода (grace period).
- При наступлении полной блокировки: отправляет финальное уведомление об отключении.
- При продлении автоматически сбрасывает флаги уведомлений.

### 4. Веб-пульт Super-Admin'а (`/super-admin` и `/super`):
- Доступ через Telegram по команде `/super` или через веб-браузер по URL `/super-admin` с защитой мастер-паролем.
- Метрики: Всего заведений, Активные, В льготном периоде, Заблокированные.
- Интерактивная таблица точек с бейджами оставшихся дней и статусов.
- **Кнопка `+30 дней`**: моментальное продление подписки точки на 30 дней и разблокировка `is_active = 1`.
- **Кнопка `Kill Switch`**: ручная заморозка/разморозка любого салона в 1 клик.
- **Модальное окно `Подключить салон`**: быстрая регистрация новых заведений сети.
- Быстрый переход в `/book` и `/admin` любой точки сети с правами суперадмина.
