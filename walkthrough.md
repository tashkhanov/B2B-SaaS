## 1. Обзор проекта и бизнес-цели

Система представляет собой автономное B2B SaaS-решение для мужского салона **Brohouse** (`@brohouseuz`, г. Ташкент), объединяющее:
- **Telegram Bot c AI-ассистентом на Gemini 2.5 Flash**: понимает текст и голосовые сообщения, ведет живой диалог, знает прайс, мастеров, филиалы и акции (-30%), оформляет бронь в реальном времени.
- **Telegram Mini Apps (TMA) — 4 интерфейса**:
  1. `client.html` (`/book`) — онлайн-запись для клиентов с выбором филиала, каруселью мастеров, категориями услуг и тайм-слотами.
  2. `index.html` (`/admin`) — панель администратора салона (записи, статусы, ручная запись, управление прайсом и с графиком мастеров).
  3. `barber.html` (`/barber`) — рабочий кабинет барбера со списком записей на сегодня, кнопками подтверждения/завершения и тумблером смены («На смене / Выходной»).
  4. `super_admin.html` (`/super-admin`) — SaaS-пульт Создателя платформы для контроля подписок, продления (+30 дней) и мгновенной блокировки (Kill Switch).

## 2. Архитектурный стек и почему не Django/FastAPI

В проекте намеренно применён высокопроизводительный асинхронный стек:
- **Язык**: Python 3.11+ (asyncio).
- **Telegram Framework**: `aiogram 3.x` (Router-архитектура, FSM, кастомные Middleware).
- **Веб-сервер и REST API**: `aiohttp` (встроенный в единый асинхронный цикл с ботом).
- **База данных**: `aiosqlite` (SQLite с поддержкой асинхронных транзакций и миграций).
- **ИИ-движок**: `google-genai` SDK (модель `gemini-2.5-flash`).
- **Стилизация**: Tailwind CSS (CDN) + Vanilla CSS (модульные стили).
- **Тесты**: `pytest` + `pytest-asyncio` + `aiohttp.test_utils`.

### Почему выбран aiohttp + чистый Python, а не тяжелые фреймворки:
1. **Единый Event Loop**: `aiogram 3` под капотом использует `aiohttp`. Сервер Mini Apps и бот работают в **одном потоке и одном цикле событий**, потребляя всего **40–60 МБ RAM** (Django потребил бы от 250 МБ) и запускаясь за **0.2 секунды**.
2. **Мгновенная реакция**: отсутствие накладных расходов ORM на сложные выборки слотов и расписания в таймзоне Ташкента (`Asia/Tashkent`).
3. **Изолированность бизнес-логики**: все сервисы (`schedule_service`, `billing_service`, `gemini_service`) написаны чистыми функциями. При будущем подключении к Django-сайту `asatkhanov.uz` их можно бесшовно переиспользовать.

## 4. Мульти-филиальная сеть (Миллий бог и Чиланзар)

У сети Brohouse два действующих филиала в Ташкенте с **единым телефонным номером**:

| Филиал | Адрес | Ориентир | Телефон |
| :--- | :--- | :--- | :--- |
| **Филиал №1 (Миллий бог)** | г. Ташкент, метро «Миллий бог», ул. 8B | Парк Миллий бог | `+998 97 012 55 55` |
| **Филиал №2 (Чиланзар)** | г. Ташкент, Чиланзарский р-н, массив Чиланзар, 2-й квартал, 58/5 | 2-й квартал | `+998 97 012 55 55` |

### Архитектурная реализация:
1. **Таблица `branches` в БД**:
   ```sql
   CREATE TABLE IF NOT EXISTS branches (
       id INTEGER PRIMARY KEY AUTOINCREMENT,
       name TEXT NOT NULL,
       address TEXT NOT NULL,
       landmark TEXT,
       phone TEXT DEFAULT '+998 97 012 55 55',
       is_active INTEGER DEFAULT 1
   );
   ```
2. **Поля в `bookings`**: `branch_id INTEGER DEFAULT 1`, `branch_name TEXT DEFAULT 'Миллий бог'`.
3. **График мастеров**: мастера подстраиваются под клиентов и обслуживают выбранный филиал.
4. **В Telegram-боте**: инлайн-выбор филиала через кнопки, карточки двух локаций по кнопке `📍 Локации`.
5. **В WebApp Client**: таб-переключатель филиалов с автоматической сменой адреса в шапке; **на экране успешной записи блок выбора филиала и скидка автоматически скрываются**, обеспечивая чистый UX.
6. **В WebApp Admin**: бейджи филиалов на карточках броней и выбор филиала при ручном вводе.

## 6. Умное расписание, слоты и балансировка мастеров

Модуль [services/schedule_service.py](file:///d:/IT/B2B-SaaS/services/schedule_service.py) реализует бизнес-логику бронирования:
1. **Таймзона Ташкента (`Asia/Tashkent`, UTC+5)**: исключены любые смещения времени сервера.
2. **Горизонт записи**: 7 дней вперед с 08:00 до 23:00 с шагом слотов в 30 минут.
3. **Автоподбор мастера (Least Busy Balancing)**:
   - Если клиент выбрал «Любой мастер», система проверяет занятость всех мастеров на смене на этот день.
   - Клиент назначается наименее загруженному барберу.
   - При равной загрузке срабатывает случайный выбор (`random tie-break`).
   - Шеф-мастер Mr. Akmal не участвует в автоподборе (запись к нему только прямая).
4. **Учёт рабочих дней мастеров**: каждый мастер имеет битовую/строковую маску дней (`work_days = "0,1,2,3,4,5,6"`).

## 7. SaaS Multi-Tenant ядро, Биллинг и Kill Switch

Модули [services/billing_service.py](file:///d:/IT/B2B-SaaS/services/billing_service.py) и [bot/middlewares.py](file:///d:/IT/B2B-SaaS/bot/middlewares.py) обеспечивают монетизацию и контроль заведений сети.

### 7.1. Модель данных `tenant_subscription`
```sql
CREATE TABLE IF NOT EXISTS tenant_subscription (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    tenant_slug TEXT UNIQUE NOT NULL,
    name TEXT NOT NULL,
    is_active INTEGER DEFAULT 1,
    expires_at TEXT NOT NULL,
    grace_period_days INTEGER DEFAULT 2,
    admin_chat_id INTEGER,
    contact_phone TEXT,
    contact_name TEXT,
    last_notification_stage TEXT
);
```

### 7.2. Логика Kill Switch (Заморозка доступа)
- **Статусы подписки**:
  - `active` — подписка активна (срок не истёк).
  - `warning` — до окончания осталось 3 дня или меньше.
  - `grace_period` — срок истёк, но действует 2-дневный льготный период.
  - `locked` — доступ заблокирован (истёк grace-период или флаг `is_active = 0`).
- **Блокировка в Telegram**: Middleware отсекает сообщения клиентов и мастеров, выдавая сообщение о технической приостановке.
- **Блокировка в WebApp**: API возвращает `403 Forbidden`, а HTML-страницы показывают стильный темный экран блокировки с замком 🔒 и кнопкой связи с Создателем (`asatkhanov.uz`).
- **Super-Admin Bypass**: Создатель (`chat_id = 1008688566`) обходит блокировку в боте и в WebApp через токен.

### 7.3. Веб-пульт Super-Admin Hub (`/super-admin`)
- Защищён мастер-паролем платформы.
- Позволяет в 1 клик продлевать любой салон на 30 дней (`+30 дней`).
- Позволяет вручную включать Kill Switch для любого салона.
- Позволяет подключать новые заведения сети.
