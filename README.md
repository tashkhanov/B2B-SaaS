# 💈 AI-Администратор для Барбершопа "Black Beard" (Ташкент)

Коммерческий B2B продукт: интеллектуальный Telegram-бот и панель управления Telegram Mini App (TMA) для премиум-барбершопа "Black Beard" в Ташкенте на базе **Telegram Bot API (aiogram 3.x)**, **Google Gemini 2.5 Flash API** и **aiosqlite**.

---

## 🎯 Ключевые возможности системы

1. **Харизматичный персонаж "Иброхим"**:
   - Вежливый, уверенный администратор с ташкентским вайбом ("ака", "братан", "без проблем", "от души").
   - Автоматическое зеркалирование языка (русский или узбекский).
   - Консультация по услугам (Стрижка — 100к сум, Борода — 50к сум, Комплекс — 130к сум).
2. **🎙 Поддержка голосовых сообщений (Voice Messages)**:
   - Клиент может отправить голосовое сообщение на русском или узбекском языке.
   - Аудиофайлы (OGG Opus) передаются напрямую в мультимодальный Google GenAI SDK (`types.Part.from_bytes`).
   - Иброхим слушает аудиозапись и отвечает в своем фирменном стиле с учетом контекста диалога.
3. **📊 Панель управления Telegram Mini App (TMA)**:
   - Встроенный мобильный веб-интерфейс в стиле **Dark Minimalist** (#0d1117, акцент #ff6b00).
   - Список всех броней из базы данных SQLite со статусами (`new`, `confirmed`, `cancelled`).
   - Кнопки быстрого взаимодействия: **«📞 Позвонить»** (`tel:`) и **«💬 Написать в TG»** (`https://t.me/...`).
   - Фильтрация: "Все", "Сегодня", "Предстоящие".
   - Вызов по команде `/admin` или специальной кнопке в меню администратора.
4. **🧠 Структурированный парсинг записей**:
   - Автоматическое извлечение имени, телефона, услуги и желаемого времени через `response_schema` в Gemini.
   - Сохранение в таблицу `bookings` и отправка красивой карточки заявки в личку администратора (`ADMIN_CHAT_ID`).
5. **⚡ Меню и системный брендинг**:
   - Команда `/about` с контактами разработчика (`@asatkhanov` / [asatkhanov.uz](https://asatkhanov.uz)).
   - Инлайн-кнопка *«🤖 Подключить ИИ в свой бизнес»* после подтверждения записи.
   - Футер в Mini App: *«⚡ Powered by Khan AI Systems»*.

## 🚀 Быстрый старт

### 1. Настройка окружения

```bash
# Активация виртуального окружения
.venv\Scripts\Activate.ps1

# Установка зависимостей (при необходимости)
pip install -r requirements.txt
```

### 2. Настройка файла `.env`

Создайте `.env` из шаблона:
```bash
copy .env.example .env
```

Укажите в `.env`:
- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather).
- `GEMINI_API_KEY` — ключ из [Google AI Studio](https://aistudio.google.com/).
- `ADMIN_CHAT_ID` — ваш Telegram ID (узнать в [@userinfobot](https://t.me/userinfobot)).
- `WEBAPP_URL` — ссылка на веб-панель (по умолчанию `http://localhost:8000` для локального запуска или публичный https-домен/ngrok для мобильного Telegram).

### 3. Запуск тестов

```bash
pytest tests/
```

### 4. Запуск проекта

```bash
python main.py
```

При запуске в консоли отобразится:
```
🌐 Сервер Telegram Mini App успешно запущен: http://0.0.0.0:8000
🚀 Бот 'Иброхим (Black Beard)' запущен! Mini App: http://localhost:8000
```
